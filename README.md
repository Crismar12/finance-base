# 💳 Finance Unified Base  
**Financial Data Analytics Project**

A data analytics pipeline that transforms **credit card statements (PDFs)** into **clean, analysis-ready datasets** for financial reporting and insights.

<img width="1023" height="277" alt="finance-base2" src="https://github.com/user-attachments/assets/d51e9e52-3e96-4bcc-9068-c284e33f9452" />

### What this project demonstrates
- Automated extraction of transactional data from unstructured documents  
- Data cleaning and normalization for analytics  
- Cloud-based data storage using a medallion architecture  
- Datasets ready for dashboards, SQL analysis, and BI tools
